# 剧本杀《深渊回响：反诈迷途》王秀兰人物本

## 第一幕：重启

> 也许在某一天，你会将自己从罪恶的牢笼中撕扯出来，真正去践行“正义”这个如此天真烂漫的字眼。一切将成为历史，可叹医者却不能自医......

1.

恍惚间，你在一阵轻微的头痛中惊醒，脑袋昏沉得厉害。

意识逐渐回归脑海，但你依旧无法动弹。

“鬼压床吗...”你只能思考。但你下意识就排除了这种可能。

慢慢地，周围传来动静，将你的身体从深渊中拉回。你睁开眼，发现自己正靠在椅子上，仿佛是午睡初醒。

“午睡？现在是几点了.......这...是什么地方？“

几缕银丝映入眼角，点破了丝丝记忆的迷雾。

你叫王秀兰，是华南大学心理学系的一名教授，半生坎坷，你终于在几年前升到了正教授的职位。你的先生似乎早已离世，唯一的儿子王奇成了你在这个世上唯一的依靠，他在华南大学毕业后，留校开启教师生涯，与你走上了同一条路。

2.

想起儿子，你总又沉浸在曾经的点点滴滴中，但关于你们的现状，却仿佛被封印在了脑海最深处，怎么想都记不起来。

出神之际，你突然听到一声女人的惊叫：”宏图集团是诈骗所有人的团伙！“

这一声猛地将你惊醒，你这才发现，自己身处一个类似会议室的空间中，你正坐在长方形会议桌的上首，顶上的中央空调滋滋通着气，似乎正在通着风而与你在一起的，还有其他六个人，有男有女。而出声的是会议桌右侧的一名中年女子，她的手里拿着一张纸条，似乎正是上面的内容。

来不及细想，你马上又被刚才女人惊呼的内容所吸引。似乎，在记忆的最深处有某些东西正在苏醒。

“宏图集团...”

“诈骗团伙...”

3.

“宏图集团，你在哪看到的？”你很快冷静下来。要过女人手里的纸条，你发现上面的字迹有些稚嫩，奇怪的是，笔迹越到后面越无力，到最后一个伙字甚至只剩下潦草的一两笔。

”我在桌上拿到的，就放在我面前的。“女人有些忐忑，她大概也失去了记忆。

旁边沙发上原本坐着的两个中年男人此时也靠了过来，房间中的众人骚动起来，有的不断低语着，有的仍在痛苦地回忆着，有的发着呆......

这时，原先坐在沙发上的其中一名男人说话了：”话说，各位，看样子大家都一样，忘了些什么，刚才我进来前看到走廊左边有一间档案室，或许能让我们知道些什么，比如这间公司的档案，这层写字楼的信息等等，我们不如一起去看看。“

这时一名比较精瘦的男子，鹰钩鼻，带着商人独有的精明。

“他怎么知道这是一家公司？”忽地，你注意到他话中的漏洞，他似乎很了解这里，或者说，他，没有失忆？

迷茫的众人也纷纷应和，你不再深想，只是留了个心眼，就也起身随众人出了会议室。

迎面是一条走廊，并不长，前头似乎还有几个房间，档案室就在你们的右手边，只不过门被上了密码锁。

### 核心任务
1. 解密之前，你们意识到大家仍然互不相识，请向大家做自我介绍。
2. 那名矮小的男人很难不令人生疑，想办法了解他为何看上去对这里如此熟悉。
3. 解开密码锁。

**请止步于此，没有主持人允许请勿翻开下一页。**

## 第二幕：往事

1.

张磊率先推开档案室的门。映入眼帘的是一排排架子，架子上陈放着一份份档案。这样的场景忽然让你产生了很奇怪的感觉，你仿佛曾无数次来到过这个地方，你仿佛曾一遍又一遍游走在排排柜子之间......

众人相继走进房间，叫做苏晴的那名年轻女人提议道：“我们还是分开找找有什么线索吧，这里空间不太大，我们一起行动太挤了......”这话确实不假，说是档案室，其实也就三四排架子，架子之间也只有半米多点的过道。

“我看...可能还是不需要了......”这时，刘敏有些胆怯的声音响起，她似乎仍在害怕着，刘敏手指着入门处左手边摆着的几张桌子，其上摆着7本档案册，王秀兰、刘敏、苏晴......所有人的档案竟已然被拿了出来！

张磊脸色难看下来：“有人在我们之前就看到了这些，这里没有别人了，你们六个中一定有人先看到了这几份档案，而恐怕，那个人就是导致我们现在这样的罪魁祸首！”这话一出，人群立马骚动了起来，似乎猜忌正在大家的心里蔓延。

赵强冷笑一声：“瞎推理啥呢？你怎么能这么肯定？就算真是这样，你可别把自己择的这么干净，我看那个人说不定就是你，如果我没记错，你可是最早醒过来的人。”

张磊丝毫不让：“哼，如果这一切都是我弄的，那我叫醒你干什么，我就不能自己溜之大吉吗？再说，我可是现场唯一一名警察，你们这时候除了我还能信谁？”

旁边的你只是冷眼看着这一幕，这个张振国给你的感觉不像一名刑警队长，倒像是一名赌徒。

气氛逐渐僵化，一直不太说话的陈凯、苏晴也埋怨起张磊无端的怀疑，你正想上前缓和一下气氛，林晓雅却率先站了出来：“够了够了，”她看上去已经受够了无谓的争吵，“事已至此，我们为什么不先看看这几份档案呢？”她顿了顿，又补充，“如果没人在撒谎，那么大家都应该是失忆了，那么大家不如都先看看各自的档案，我们再来做进一步的交流。”

不愧是大学生，他们总能在局面最僵化时自愿当出头鸟。你对她不禁有些欣赏，你一定曾知道这个学生，只不过什么都回想不起来了。

无人反对，大家默默上前，拿走属于自己的那份档案。

找了个能挡住所有人视线的角落，你打开档案，尘封的过往瞬间席卷而来，压得你喘不过气。

2.

你叫王秀兰，一辈子深耕心理学领域，在大学里教书育人，受人敬重，本该安稳度过余生，却被宏图集团彻底打乱了人生。

二十年前的一个雨夜，你的丈夫在暴雨中打错了方向盘，冲出了山崖，车毁，人虽未亡，但也岌岌可危。高昂的医药费像小山一样压住你的身心，走投无路之际，一家公司推出的高利息贷款成为了你最后的救命稻草，在对方客服的逐步诱导下，你越陷越深，直到有一天，你突然发现你几十万的积蓄被一扫而空，而没过几日，你的丈夫也陷入了永远的长眠。那日起，你的心理开始逐渐扭曲，医者不能自医，谁能想到，平日里在讲台上讲授着种种心理学知识的教授，竟无法愈平自己心里的创伤。

此后，你的儿子王奇成了你唯一的依靠，他就像你人生中唯一的灯塔，孤单地矗立在人生的海洋中。你发誓要给王奇这世界上最好的一切，然而没有钱的支持，一切都只是空谈。

你开始利用你在大学中的人脉创业。可是，即使大学中的朋友同事由于同情你给了你极大的支持，你依旧因为经验不足而一次又一次地碰壁。绝望之际，你回想起曾经被诈骗的经历，潘多拉的魔盒打开......

3.

你终究走上了那条路......

你“有意或无意”地开始与某些诈骗团伙接触，那家从前将你骗得一无所有的公司成为了你的首选。你竟然对这家害得你家破人亡的公司没有任何怨念，或许，你的心理早已扭曲......从老年消费者的心理，到年轻人面临毕业即失业的急躁，你往往能洞穿人心，准确把握住他们的痛点，击溃他们的心理防线。这使你很快帮助集团收割了大批消费者的钱财，你也逐渐取得了公司的信任。

对外，你们只是一家名为“宏图集团”的金融公司。很多骗来的赃款通过种种金融手段被洗干净。你隐约间还听说公司有一位技术高手，为公司带来了一项能快速转移赃款至境外的装置，至于是怎么实行的，你一概不知。

随着规模逐渐扩大，越来越多的目光开始注视向你们，你听说，大概在十年前，一名老刑警揪出了你们的蛛丝马迹，还是公司头目早有准备，早早将公司拆分成多个独立的部分，这些部分的规模都极小，有的甚至只是一层写字楼的一小部分。这样，你们不至于被连根拔起，居于幕后的头目更是稳如泰山。

集团并没有亏待你，那位公司的“头目”甚至多次与你通话交流，尽显“招揽人才”之意，但你却从来没有见过他，变声器下，你甚至连他是男是女都不得而知。但以你的经验和心理学知识判断，你认为对方是个女性。

4.

你和王奇的生活蒸蒸日上......

有了金钱开路，王奇的成长之路异常顺利，你不忍他受到一点委屈；他重走了你的路，特别是在你的母校——华南大学这所名校里，你在校里的关系和大笔金钱并行，在五年前，王奇顺利博士毕业，更是成为了学校里有史以来最年轻的导师。

可你自己也知道，王奇并没有什么真本事，全靠你为其铺路。自十几岁来便一帆风顺的王奇颇有“纨绔子弟”之风，他仗着自己你的特殊关照总干出些违规乱纪的事，更有甚者，常暗地里暗示女学生给他一些“好处”，那名女学生不答应，多次尝试未果，王奇恼羞成怒，对这名女学生毕业、实习等方面层层阻碍，一度将女学生逼得想要自杀。

许多学生无法忍受，多次举报王奇学术不端等等，都被你动用“钱权”压了下去。由于你在公司很受重视，甚至隐隐成了集团的“首席顾问”，因此公司也动用了利益网帮你解决了有关王奇的部分问题。你也多次告诫王奇让她受收敛点，可也总不如你意。

两年前，你私底下了解了那名女孩，你知道她叫林轻舟，据她曾经的辅导员说，她极其上进努力，能力也很强。只是最终摊上了这样一个导师......说及此，那老师偷偷看了你一眼，不再谈下去。

叹了一口气，你摆摆手，示意没关系。你在旁人眼中一直是一名平易近人的老教授形象，除了极其护子这一点，大家其实对你的印象都很好。

一切仿佛如常，但在了解之后，你的内心总感觉到隐隐的不安。你看过那名女孩的照片，那纯真的笑容你已经几十年没有见过了，那是多么美好和充满希望。连你自己也觉得莫名其妙，你开始默默关注那名女孩，你甚至会接着女孩心理测试分数不够的借口，与其谈话。你运用自己的谈话技巧和心理学知识，逐渐将女孩的心从绝望的深谷拉回日常的点滴。女孩也慢慢开始走出阴影，有一次的谈话中，林晓雅甚至与你聊起她的过往。你震惊的得知，她在去年也有过被诈骗的经历，而在她倔强的私下调查后，她开始怀疑起一家名为“宏图集团”的公司，并已掌握了小部分证据......

4.

叹口气，你怀着复杂的心情继续看下去。女孩的经历深深刺激到了你，你从来没觉得你是如此的虚伪。

那一日的谈话在此后如针扎般折磨着你的心灵，你主动联系到公司头目，你希望金盆洗手。

电话中，你是如此坚定地说出自己的决定，可是对方只是冷笑一下，发来一份文件，你打开，心顿时凉了半截，那是你儿子近几年来各种违规乱纪的全部证据。

“你好好想想吧。”冷酷，无情，与以往所有的关心截然不同。你愣愣地挂掉电话，翻盖手机掉在地上而不自知。没有办法，你只好继续为集团效力。但同时，你也暗暗支持起林晓雅的调查事业，林晓雅的能力很不错，你在公司中还是有些人脉，于是你偷偷为其在公司中谋了个小文职，这不仅是为她，更是为了你自己，你希望能揪出那个头目，从而去摆脱控制。

一年间，你们联络上了几个同样被诈骗的受害者。令你没想到的是，公司的前台苏晴竟也是潜伏在公司中的“卧底”。据她所说，在几年前在一次被骗后，她就开始了暗中的调查，只是她没想到骗自己钱的竟然就是自己的公司！与其经历相似的还有她的老乡刘敏，她在宏图中负责的是文件整理，只不过她的性格很胆怯，完全不敢去与集团做对。谈话时，她几乎不太说话，只是一味着附和着我们，紧跟着我们。它更像一个乡下来的，朴实，老实是她最大的特点，她只是习惯在一旁记录着什么。

“我一定要复仇。”苏晴的眼神坚定语气果决。“既然警察什么都查不出来，那就我们自己来查！”

连警察都查不出来，单靠我们的力量几乎不可能成功扳倒宏图集团。而且我自己绝对不能出面，只能由别人出面。

我积极劝说，又成功拉上了其他几个受害者。

你们在私下里逐渐形成了一个组织，虽然许多人你线下并不真的认识，但你们不断尝试着通过各种渠道搜集相关线索。

在这里，你丰富的经验和能力让你逐渐成为几人的领导者，那一段日子仿佛在黑夜中迎着烛光匍匐前进，你也终于看到了许久许久未见的光。

大概在一个月前，你们组织7人终于决定将所有的证据汇总起来，整理成正式的文件。你预约了一栋老式写字楼的一间会议室，在许多年前你曾在那开过会，你知道那里几近荒废，安全性和隐蔽性应该可以保障。

决战，即将开始......

5.

档案在这里戛然而止，似乎就是不久前有人整理出来的。你依旧保持着吓人的平静，只是隐隐还在担忧着你的儿子王奇。档案室里一片沉默，你看到林轻舟还在读着档案，赵振国不知何时看完，早点起根烟，一脸阴沉地抽着。透过缕缕烟雾，你看到不远处苏晴和刘敏倚着墙也是默默无言，各自怀着心思的样子。另外两人，或许是被架子挡住，你并没有看到他们。

翻动档案册，你思考着这一切，当年的骗局究竟是怎样的，宏图集团的头目究竟是谁，你们每个人的档案为何又会出现在这，你们又为何会失忆？

......

偶然间，你看到了档案最后一页的空白处有小字，字迹隽秀，那不是你的笔迹：“究竟是谁在骗我......”笔力很重。

“骗？”你苦笑了一下，你骗过的人还少吗......

### 本幕任务
1. 还原自己的被骗经历并向DM阐述诈骗方式，如实说出自己被宏图集团理财诈骗的经历。
2. 隐瞒自己担任心理顾问、为集团提供受害者分析的事实。
3. 个人任务：查清档案出现在这的原因；探查在你档案后留下字的人。
4. 隐瞒自己被骗经历在很早前的事实，否则你显得和众人格格不入。

## 第三幕：缉凶

一番交流之下，你们逐渐意识到你们出现的这个地方是有人故意为之。因为这里正是宏图集团的隐藏据点之一，你们几人的档案又恰好储存在这里。

“这一切太过巧合了。”张振国沉吟道，他盯着你，“而你，把我们聚集到了这里来，不管怎么说，你的目的绝不简单。”

你皱了皱眉，你承认这一切确实太过巧合了，但你确实没有做任何多余的事情，你开始意识到你们的团队里有内鬼，而那个人的目的很可能是通过让他们“失忆”的方式将证据彻底从世界上抹除。而这个张磊，自称刑警，却丝毫没有警察的严谨态度，从头到尾他都只是没有理智地猜忌他人。

“我觉得现在比起在这里互相怀疑，不如去别的地方找找看有没有别的线索，争取尽快抓出宏图集团的头目。”你不去理张磊，而是转而对其他人说道。

刘敏也跟着附和：“对啊，我们还是不要一直争吵了。”

这一层楼并不大，会议室出来就是走廊，而走廊连通着其他房间。

众人决定分组行动，你让林晓雅、刘敏留在档案室，继续查找核心证据；而你们其余人前往其他地方探查。

进入走廊中，你越来越觉得这里很熟悉，你似乎曾来到过这里。你们决定分组到各房间看看。“我去看看杂物间吧，你们可以留一部分人去别的地方看看。”作为最年长者，并没有人反对你的决定。

最终，只有陈凯跟上你，他似乎也很想去杂物间。这个年轻男人似乎不太有存在感，他几乎没说过话。你一眼觉得他像个程序员，他的脸色很苍白。你走在前面，打开杂物间的门，进入其中。

房间不大，只有十几平米的样子，堆满了包括各种杂物。与之很格格不入的是一旁木桌上的几枚U盘，你上前拾起，发现有一个标着林晓雅，另外三个则不知是谁的。

刚把它们收起来，你就发现陈凯对这里很是熟悉，四处摸索着，太过专注，就连自己的腿狠狠撞到了桌角他都没有反应。他在墙上找着什么，然后猛地按下一个按钮，突然，一个暗门浮现，慢慢打开，只见里面是一个更狭小的房间，房间正中央摆放着一台奇怪的机器，房间的一侧还有一台电脑，一根根线与机器相连。

“陈凯，这是什么？”此时就算你也完全无法控制自己的惊讶，你隐约回忆起了什么，与这台机器有关。

## 第四幕：真相

苏晴的话如利剑一般深深扎在你的心里。众人竟没有一个人反驳的，不知该如何是好，你们又看向张振国，这样一件刑事案件还是警察最有发言权。

张振国看到众人看向自己，却眼神躲闪起来：”大家放心，我们肯定会把他绳之以法的，只是...只是现在我们根本出不去啊。“

你的心里一惊，出不去？“门都被锁了？”林轻舟冲出监控室，果然发现不管是消防通道还是电梯，均被锁住了。

“之前我和张警官醒来时就在走廊上，我们检查了所有的通道，发现均无法打开。”赵强无奈说道。

之前的不安感彻底在你心中炸开，你突然意识到一件极为奇怪的事，你们每个人似乎都没有任何想要先从这里出去的想法，而这根本不符合正常人的思维，你们似乎就连自己的意识都被困在了这里！

一个大胆的想法浮现在你的脑海中。

这时，赵旺来颤颤巍巍地说到：“我想，我们可能都已经......已经......”

“已经什么？”张振国不耐烦的问道。

“死了。”

如惊雷般在人群中炸开，包括你的所有人呆在原地。

你的想法，是真的......

“清洁室的通风装置被开启了，而且，而且显示正在释放剧毒气体，吸入者在一两分钟内就会死亡......”苏晴开口了，此时她的脸颇为苍白。

“刚才在清洁室中看到我还不敢确定，只是在观察了你们的状态后，我终于确定了这不是一个玩笑......”赵旺来补充道。

你们确实都死了......死于原本用来通风的换气机。而不知出于什么原因，你们的意识又重新回到了这里，而且你们几乎失去了之前所有的记忆......

丝丝气流还在不断地从风口送出。你并没有感到任何恐惧，你似乎不害怕死亡，甚至一丝久违的解脱之感在心底里升起。

你回想起那样你生命中唯一珍贵的东西，它像一个锚点，将你真正的记忆慢慢拉了出来。

3.

二十年前带走你丈夫的并非什么车祸，而是黑色产业间的“黑吃黑”，没有什么悲惨身世，你继承了你丈夫的“诈骗帝国”，你依靠自己丰富的心理学能力迅速稳定住了人心，在极短时间内控制住了局面。当然，利用之前遗留下来的权力结构，你完全不用暴露自己的真实身份，你在暗地里操控着这一切。

你在全市各地安置了多个据点，其中就包括现在所处的这一层写字楼，你会将每一个诈骗过的人的全部信息都储存在这里，你时不时会到这里来或像是翻阅一篇篇作品，或像是进行某种忏悔般翻阅这些文件。十几年来，无数的罪恶无时无刻不在腐蚀着你的良心。在无数个深夜，你无数次想要就此停手，但你知道，走上了这条路就再没有回头路了。

你的心在不断扭曲......
