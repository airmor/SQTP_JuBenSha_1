# 玩家推理任务（供主持人与发放线索用）

说明：依据流程与人物本，按四幕（重启 / 往事 / 缉凶 / 真相）列出公开任务与每名玩家的个人任务。每项任务下列出可作为线索卡的候选线索（不少于20条，含部分误导线索）。主持人可择取、裁剪、印制线索卡并按需分发。

## 第一幕：重启

### 公共任务（全员）
- 目标：确认彼此身份、互相介绍、解开档案室密码并进入档案室。
- 线索卡候选（至少20条）：
	2. 桌面上一枚未识别的钥匙（无名牌）。
	3. 会议室门外地板的一小滩干涸液体痕迹（清洁剂残留味）。
	4. 走廊地面的一处鞋印（右脚鞋底缺口）。
	5. 密码锁面板上残留的指纹拍照（模糊，可进行比对）。
	6. 会议桌下的一张老旧名片：写着“宏图集团 · 项目部”。
	7. 每人面前的座位上都放有一张姓名贴（但字迹不同寻常）。
	8. 会议室上方中央空调的检修记录（5天前有一次异常开关记录）。
    10. 一张会议邀请邮件打印件（时间不完整，有被划掉的时间段）。
    11. 密码锁旁边一只掉落的笔，笔帽上有血迹（淡，可能为旧伤）。
    12. 档案室门框上的轻微划痕（像是撬动痕迹）。
     13. 档案室门口地毯上一根女性长发（可做DNA/比对线索）。
    14. 一张写有“请按顺序说出姓名并交档案”的便签（表面上像是主持指令）。
    15. 一张回执单：租赁写字楼的合同（公司名称被涂改痕迹）。
    16. 一张监控截图（模糊）：走廊光线中有人影一闪而过（可做误导）。
     17. 七本档案被事先摆放的照片（有人提前翻动的证据）。
    19. 一段被剪接的语音文件（手机录音，含“...别忘了14:50...”蒙太奇）。
    20. 一张写着“记忆弧光启动需30s，生效再30s”的草稿（模糊的技术笔记，误导用）。
